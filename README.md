# temires-files

Публичные файлы для сайта [temires.kz](https://temires.kz): презентация компании, фоновое видео первого экрана и фото продукции. Сайт берёт их через CDN jsDelivr, например `https://cdn.jsdelivr.net/gh/lumeincc/temires-files@v1/temires-presentation.pdf`.

| Файл | Что это |
|---|---|
| `temires-presentation.pdf` | Презентация ТОО «ТемирЭнергоСтрой», 18 слайдов |
| `hero-720.mp4` | Фон первого экрана для компьютеров, 1280 × 720, 17,4 с, без звука, зациклен без шва |
| `hero-540.mp4` | То же для телефонов, 960 × 540 |
| `hero-poster.jpg` | Первый кадр видео: показывается, пока видео грузится |
| `photos/pir-*.webp` | Печи-инсинераторы с площадки, поставленные в светлую студию: фон, пол с отражением и тень, 1400 × 1120 |
| `photos/bmz-*.webp` | Блочно-модульные здания в той же студии, 1400 × 1120 |
| `photos/kotelnaya-blok.webp`, `photos/kotelnaya-bloki.webp` | Котельная в блок-контейнерах, в той же студии, 1400 × 1120 |
| `photos/kotelnaya-dve-pechi.webp`, `-topka`, `-nasosy`, `-pult` | Котельная изнутри: печи, топка, насосы, пульт, 1400 × 1120 |
| `photos/kotel-zelenyi.jpg`, `photos/kotelnaya.jpg` | Котельные: живые кадры после ретуши, 1500 × 1200 |
| `photos/shkaf-upravleniya.jpg` | Шкаф управления инсинератора, 1500 × 1200 |

Видео первого экрана собрано из трёх роликов с [Pexels](https://www.pexels.com/license/) (бесплатная лицензия, без указания автора): [расплавленный металл из печи](https://www.pexels.com/video/melted-metal-coming-out-of-furnace-5121743/), [сварка в замедлении](https://www.pexels.com/video/slow-motion-of-welding-in-factory-11887094/), [резка на станке с ЧПУ](https://www.pexels.com/video/industrial-laser-cutting-machine-operation-34716349/).

Новую версию файлов выкладывайте с новым тегом (`v2`, `v3`…) и меняйте тег в ссылках на сайте: так CDN сразу отдаст новый файл.
